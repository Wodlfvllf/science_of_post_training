# Counter-hypotheses after the initial routing nulls

Development plan, 1 November 2026. Nulls at selected groups/rows reject the tested
explanation, not every possible distributed computation. No confirmation data
will be opened to find a positive story. These alternatives may also fail.

## C1: Task-conditioned text-state bottleneck

**Prediction:** native pre-answer residuals from a destination-shape task contain
information that can change the corresponding recipient destination-color
answer, even when direct image-route Q/K interchange is ineffective.

Initial scope is four engineering families, both traversal directions, one
palette, four prespecified zero-based layers (8/16/24/32), and two text rows:
the first destination task noun and the final assistant position. There is no
layer-adaptive extension or correctness-filtered denominator in this screen.
All data/model/scorer pins are unchanged; open-assistant conditioning and task
wording are explicitly separate from the original locked baseline.

Six independently evaluated residual conditions:

1. Native, unmodified.
2. Self-patch: same native recipient vector.
3. Shape-task vector from the same image, before any donor response.
4. Same shape task and geometry with disjoint donor colors.
5. Color-task disjoint-palette control.
6. Wrong-anchor shape task with disjoint colors.

Only one text row after the selected native decoder block is replaced. Image
rows, embedding inputs, weights and other rows are not directly edited. Unlike
Q/K routing patches, the residual includes task/format/other information; rescue
alone cannot identify a pure selector. Within-checkpoint native states only.

**Mandatory checks:** exact full token/rotary row alignment; actual word-end
prefix mapping; CPU-owned finite vectors; native/capture/self score and logit
parity; hooks removed after all calls/errors. Shape/color residuals at traversal
tokens before the differing task words must be bit-exact equal for the same
image, a causal structural control. Donors have no scored/generated answers.

**Endpoints:** report recipient-gold and anchor-copy rates, target-minus-anchor
score margins, wrong-role recipient colors and disjoint-donor color copying.
Report lowercase, title-case and distinct-prefix pooled scores separately; do
not choose a favorable casing after seeing results. First-family patched greedy
audits at layer 24/final-assistant cover all six conditions, including shape-word
output, explanations and EOS/truncation. Format invalidity is not semantic zero.

**Lead criteria:** role-specific recipient-palette effects beyond color-task
shams, including wrong-role predicted colors; no donor-color/output-type copying.
A shared effect in MPO and GSPO is not an acquired post-training mechanism.
Four families are a screen, not a significance or preservation claim. A lead
requires a frozen discovery replication, task/state blocking, bounded weight
tests, and only then untouched validation/confirmation. No paper claim is earned
by residual transplant alone.

## C2: The direct-answer task is compositionally underspecified

If C1 is unsupported, test a **model-generated**, not gold-supplied, decomposition
on engineering families: first predict the destination shape; ask for its color
in a separate cued query; compare end-to-end correctness and error propagation
against the same model's direct answer. Also compare a no-image/text-fact version.
This tests an alternative computational trajectory, not latent reasoning in the
original prompt. Oracle shape cues may be a labelled upper-bound control only,
not a claimed rescue. Freeze wording/budgets before replication.

The implemented first C2 screen fixes 32-token uncached greedy budgets and uses
strict EOS-terminated bare shape predictions only. Failed/invalid shape delivery
does not fall back to the highest-scored candidate. Its wrong-selector control
cues the next entry in the fixed shape vocabulary relative to the **prediction**,
not relative to the oracle target. That cue can accidentally equal the true
destination; report this explicitly rather than calling every control incorrect.

## C3: Selection interference depends on anchor or representation

If native generated decomposition still fails, use fresh engineering scenes to
contrast marked anchors with shape-named anchors, and single-edge versus cyclic
layouts. Counterbalance anchor/target/distractor colors and query roles. A new
renderer/task requires a new source-pinned protocol and fresh held-out families;
never replace labels/images in the current plan. Better assay accuracy alone is
not a mechanism or a novel paper contribution.

## What must not be claimed

- Failed selected patches do not prove absence of all routing/selector states.
- A residual rescue is sufficiency under a changed state, not native necessity.
- Released endpoint differences do not identify a causal optimizer effect.
- New tasks, more GPUs, or more significant comparisons cannot repair missing
  novelty or justify using confirmation for hypothesis search.
